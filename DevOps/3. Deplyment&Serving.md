## Network
### How does the devices (visual device) communicate?
- (general): Container IP -> routing -> NAT -> internet gateway ->  Internet. 
- (aws): EC2 -> VPC -> NAT Gateway -> Internet Gateway -> Internet. 

NAT(network address translation): let a device acessess the external resources with public ip address.k

An ip has many different ports like house having different doors, application communitates through the ports. 

In the case of the Docker, we have the **bridge mode**, which is 
- container IP -> docker NAT -> host IP -> network
It is more complicated compared to the **host mode**, which directly uses the host network.
