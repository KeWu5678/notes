## Database
### In-memory Database (Redis)
the online database: very low-latency, very high cocurrency. 

### Data Warehouse (redshift)
Indexed/Optimized data: low-latency, high cocurrency. 

### Data Lake (Athena/S3 bucket) 
Anything else.

  The cost/latency tradeoff in one picture                                                                   
   
  fast / expensive                                 slow / cheap                                              
     │                                                       │                                               
  Redis ──── Redshift ──── Athena ──── S3 (cold/Glacier)
   µs           ms            sec          minutes+                                                          
                  
  You move data down the ladder as it cools off (recent → cached in Redis, last month → Redshift, last year →
   S3 Parquet, archives → Glacier).

## Feature store
### preprocessing the data
basic null filtering, shape validation, type coercion

### the aws object
The aws base object allows for batch operation of feature groups. 
```FeatureGroup```: schema + record identifier + event_time
```FeatureGroup.ingest()```: batch ingestion
