## statement

Let X be a right continuous submartingale. Show that under any of the following conditions the set {Xτ ∶ τ ∈ TT } is uniformly integrable for all T ≥ 0. • Xt ≥ 0 a.s. for all t ≥ 0. • X admits the Doob-Meyer decomposition Xt = Mt + At where M is a martingale and A is an increasing adapted process.
