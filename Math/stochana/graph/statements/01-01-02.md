## statement

The stochastic processes X and Y have the same finite dimensional distributions if P[Xti ∈ Bi for all i = 1, .., n] = P[Yti ∈ Bi for all i = 1, .., n] for all 0 ≤ t1 ≤ ... ≤ tn , all n ∈ N and all Bi ∈ B (i = 1, ..., n).
