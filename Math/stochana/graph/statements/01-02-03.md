## statement

Let (Ft ) be a filtration on (Ω, F, P). • The mapping τ ∶ Ω → I¯ is called a stopping time if {τ ≤ t} ∈ Ft for all t ∈ I. We define Fτ ∶= {A ∈ F ∶ A ∩ {τ ≤ t} ∈ Ft for all t ∈ I} • The mapping τ ∶ Ω → I¯ is called an optional time if {τ < t} ∈ Ft for all t ∈ I. We define Fτ + ∶= {A ∈ F ∶ A ∩ {τ < t} ∈ Ft for all t ∈ I}
