## statement

• Let (E, B) be a measurable space and I be a non-empty index set. For any set B ∈ B there exists a countable set S ⊂ I such that for any pair (x, y) ∈ E I × B the following I implication holds: x(t) = y(t) for all t ∈ S implies x ∈ B.
