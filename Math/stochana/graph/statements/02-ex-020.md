## statement

(*) Let us consider the following σ-algebras on C = C[0, 1]: • the Borel sigma-algebra B(C); • the sigma-algebra σ(C) generated by continuous functions f ∶ C[0, 1] → R, i.e. ⎛ ⎞ σ(C) ∶= σ ⋃ {f −1 (B), B ∈ B(R)} ; ⎝f ∈C ⎠ • the sigma-algebra σ(Z) generated by the system Z of all cylinder sets Z = {x ∈ C ∶ x(tj ) ∈ Aj , j = 1, ..., n}, with n ∈ N, 0 ≤ t1 < t2 < ⋯ < tn ≤ 1 and A1 , ..., An ∈ B(R). Show that σ(C) = B(C) = σ(Z). In particular, the mapping X ∶ (Ω, F) → (S, B(S)), ω ↦ X⋅ (ω) is measurable if and only if for all ti ∈ [0, 1] the coordinate evaluation mapping ω ↦ Xti (ω) is measurable. Hint. To show that B(S) ⊂ σ(Z) show first that every closed ε-ball is in σ(Z) and then use separability of the metric space S to conclude. To show that B(S) ⊂ σ(C(S)) let A ⊂ S be closed and find a function h ∈ C(S) such that A = {h = 0}.
