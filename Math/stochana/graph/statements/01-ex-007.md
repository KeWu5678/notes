## statement

i) Show that every stopping is an optional time and that the two concepts coincide if the filtration is right-continuous. ii) Show that for any stopping time τ the set Fτ is a σ-field. iii) Show that for any stopping time τ the set {τ ≤ s} belongs to Fτ for all s ∈ I; in particular, τ is Fτ -measurable.
