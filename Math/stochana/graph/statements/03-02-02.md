## statement

We emphasize that we used the same sequence of partition of every ω when computing the quadratic variation of Brownian sample paths. If we were allowed to choose different partitions for different sample paths, then we could obtain any quadratic variation, including the zero process. For instance, on can prove that for any continuous function f ∶ [0, 1] → R there exists a sequence of partitions {Πn }with mesh sizes going to zero, such that Vt2 (f, Πn ) → 0 for all t ∈ [0, 1]. 3.2.1 The basic Itô formula
