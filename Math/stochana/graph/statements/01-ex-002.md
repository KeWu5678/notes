## statement

(*) i) Show that the progressive σ-field is the σ-field on Ω × [0, ∞) is given by the set {A ⊆ Ω × [0, ∞) ∶ A ∩ (Ω × [0, t]) ∈ Ft ⊗ Bt } . In other words, show that a process is progressively measurable if and only if it is measurable w.r.t. the progressive σ-field. (ii) Show that the σ-fields generated by the following sets of functions coincide: a) the set of adapted left-continuous functions b) the set of all elementary functions, that is functions of the form n Xt (ω) = e−1 (ω) + ∑ ej (ω)1(tj ,tj+1 ] (t) j=0 where 0 = t0 < t1 < .... < tn and ej is Ftj -measurable and e−1 is F0 -measurable and bounded. c) the space of predictable processes of the form: for A ∈ Fs with s > 0, respectively, A ∈ F0 Xr (ω) = 1A×(s,t] (ω, r), Xr (ω) = 1A×0 (ω, r) d) the space of continuous functions.
