## statement

(Arzelà, Ascoli) Let K and S be metric spaces where K is compact and S is complete, and let D ⊆ K be dense. Then a set A ⊆ C(K, S) is relatively compact if and only if {xt ∶ x ∈ A} is relatively compact in S for any t ∈ D and lim sup w(x, h) = 0. h→0 x∈A In this case, even the set ⋃t∈K {xt ∶ x ∈ A} is relatively compact in S.
