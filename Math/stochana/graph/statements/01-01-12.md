## statement

A stochastic process B on a probability space (Ω, F, P) is called (standard) Brownian motion (BM) if B0 = 0 and B has • independent increments: for all 0 ≤ s1 ≤ s2 ≤ ... ≤ sn ≤ s < t < ∞, Bt − Bs ⊥⊥ (Bs1 , ..., Bsn ) • stationary increments: for all 0 ≤ s < t < ∞, Bt − Bs ∼ N (0, t − s) • almost surely continuous sample paths
