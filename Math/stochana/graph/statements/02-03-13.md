## statement

(Riesz–Markov–Kakutani Representation Theorem) Let X be a compact Hausdorff space and L ∶ C(X) → R be a positive linear functional, i.e. L(f ) ≥ 0 whenever f ≥ 0. Then there exists a unique regular Borel measure µ on X such that L(f ) = ∫ f dµ for all f ∈ C(X). X Moreover, ∥L∥ = µ(X). In particular, if L(1) = 1, then µ is a probability measure.
