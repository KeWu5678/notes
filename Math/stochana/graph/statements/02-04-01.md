## statement

Let (Ω, F, (Ft ), P) be a filtered probability space. An adapted process B is called a Brownian motion w.r.t. the filtration (Ft ) if • B0 = 0 a.s. • Bt − Bs ⊥⊥ Fs for all 0 ≤ s ≤ t < ∞ • Bt − Bs ∼ N (0, t − s) • B has almost surely continuous sample paths.
