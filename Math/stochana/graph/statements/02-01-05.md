## statement

(Brownian bridge) Let I = [0, 1]. We want to construct a Gaussian process X that starts and end in 0. One possibility is to choose a Brownian motion B and to define Xt ∶= Bt − tB1 , t ∈ [0, 1]; we will see an alternative construction later. Then, for all 0 ≤ t1 ≤ ... ≤ td < 1, ⎛ 1 0 0 ⋯ 0 −t1 ⎞ ⎜ 0 1 0 ⋯ 0 −t2 ⎟ ⎜ ⎟ (Xt1 , ..., Xtd ) = A(Bt1 , ..., Btd , B1 )t , A=⎜ ⎟. ⎜ ⋯ ⋯ ⋯ ⋯ ⋯ ⋯ ⎟ ⎜ ⎟ ⎝ 0 0 0 ⋯ 1 −td ⎠ Hence, X is a Gaussian process; its covariance function can easily be computed: for each 0 ≤ s ≤ t ≤ 1 E[Xs Xt ] = E[(Bs − sB1 )(Bt − tB1 )]
