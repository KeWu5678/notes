## statement

Let X ∶ Ω → R be right-(or left-)continuous and adapted. Prove that the first entrance time to an open set is a stopping time if the filtration satisfies the usual conditions. Give an example that shows that the first entrance time to an open set is not necessarily a stopping time if the filtration does not satisfy the usual conditions.
