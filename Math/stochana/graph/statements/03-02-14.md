## statement

For a given family X1 , ..., Xn random variables with common density function f (⋅, θ) with unknown parameter θ the likelihood function is given by the function L(θ) ∶= f (X1 , ..., Xn , θ). The maximizer θ̂ of the function L(θ) (assuming it is unique) is called the maximum likelihood estimator (MLE) of θ, given X1 , ..., Xn . The MLE is called consistent if θ̂ → θ a.s. if n → ∞.
