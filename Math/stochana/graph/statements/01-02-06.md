## statement

Let X be a progressively measurable stochastic process and τ be a stopping time. Then the random variable Xτ (ω) ∶= Xτ (ω) (ω) defined on {τ < ∞} (and only there!) is Fτ -measurable. Moreover, the stopped process X τ = (Xτ ∧t ) is progressively measurable.
