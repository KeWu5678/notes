## statement

For a stochastic process X we denote by F̃tX ∶= σ(Xs , 0 ≤ s ≤ t) the filtration generated by X and put X F̃∞ ∶= σ(Xt ∶ t ∈ I). The completion of (F̃tX ) is defined by FtX ∶= F̃tX ∨ N for all t ∈ [0, ∞]. 1 For two sets A and B the symmetric difference A∆B is defined by A∆B = (A/B) ∪ (B/A).
