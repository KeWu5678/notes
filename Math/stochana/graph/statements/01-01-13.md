## statement

A stochastic process N on a probability space (Ω, F, P) is called Poisson process with parameter λ > 0 if • N0 = 0 • N is a càdlàg process • N has independent increments: for all 0 ≤ s1 ≤ s2 ≤ ... ≤ sn ≤ s < t < ∞, Nt − Ns ⊥⊥ (Ns1 , ..., Nsn ) • N has Poisson distributed increments: for all 0 ≤ s < t < ∞, (λ(t − s))k −λ(t−s) P(Nt − Ns = k) = e k! More generally, a stochastically continuous process X is called a Lévy process if X0 = 0 and if X is a càdlàg process with stationary independent increments.
