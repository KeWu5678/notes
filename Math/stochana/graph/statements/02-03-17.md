## statement

Let X be a Polish space and let (µn )n∈N be a sequence of probability measures on X. Assume: 1. Tightness: For every ε > 0, there exists a compact set K ⊂ X such that sup µn (X ∖ K) < ε. n 2. Pointwise convergence on Cb (X): There exists a bounded, positive, linear functional T ∶ Cb (X) → R such that ∫ f dµn =∶ Tn (f ) → T (f ) for all f ∈ Cb (X). X Then there exists a unique probability measure µ on X such that T (f ) = ∫ f dµ for all f ∈ Cb (X). X
