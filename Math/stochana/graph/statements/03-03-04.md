## statement

Let T be the class of all finite-valued stopping times and TT be the class of all stopping times bounded by T > 0. A stochastic process X is said to be of class D, respectively of class DL if the set {Xτ ∶ τ ∈ T }, respectively, {Xτ ∶ τ ∈ TT } is uniformly integrable for all T > 0.
