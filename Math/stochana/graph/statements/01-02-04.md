## statement

Let I = [0, ∞) and let X ∶ Ω → R be right-(or left-)continuous and adapted. Let Γ ⊂ R be non-empty, and consider the first entrance time τΓ ∶= inf{t ≥ 0 ∶ Xt ∈ Γ} (inf ∅ ∶= ∞). • If Γ is open, then τΓ is an optional time. • If X is continuous and Γ is closed, then τ is a stopping time.
