## statement

(Helly’s selection theorem) Let V be the class of all right-continuous, increasing and bounded function F ∶ R → R. Let {Fn } ⊂ V be uniformly bounded. Then there exists F ∈ V and a subsequence {Fnk } such that Fnk (x) → F (x) for all x ∈ R in which F is continuous.
